# 工作日志：Google 计费审计 + 配额闸门收紧 + 鉴定改为需登录

**日期**：2026-09-17
**起因**：老板质疑「本月 Google 账单 ¥0」的结论 —— 各子 API 的免费额度并不一样

---

## 一、错在哪里：免费额度是按 SKU 给的，而且差一个数量级

Google Maps Platform 从 2025-03 起废掉了 $200 统一抵扣，改成 **per-SKU 免费额度**，
按产品档位（Essentials / Pro / Enterprise）给，分别是 **10,000 / 5,000 / 1,000**。

我们实际用的四个接口（旧版 Places API）对应：

| 我们调的接口 | 计费 SKU | 免费额度/月 | 超出单价 |
|---|---|---|---|
| `place/photo`（照片代理 `/api/photo`） | Places Photo（Enterprise）`81E7-85D0-58A7` | **1,000** | $7 / 1000 |
| `place/details/json` | Places Details（Pro）`FC5C-DF28-543F` | 5,000 | $17 / 1000 |
| `place/textsearch/json` | Places - Text Search（Pro）`E95A-86C7-7F47` | 5,000 | $32 / 1000 |
| `place/nearbysearch/json` | Places - Nearby Search（Pro）`6B23-8A17-D29D` | 5,000 | $32 / 1000 |

旧代码给所有 SKU 用同一个 `DEFAULT_BUDGET = 9000` 并写死「每个 SKU 免费 10000」注释 ——
**照片那个只有 1000**，等于默许超过 1000 之后一直按 $7/1000 计费。

### 实际损失（2026-09 截至 09-17）

| SKU | 本月调用 | 免费额度 | 超出 | 费用 |
|---|---|---|---|---|
| photo | 2,238 | 1,000 | 1,238 | **$8.67** |
| details | 236 | 5,000 | 0 | $0 |
| nearbysearch | 6 | 5,000 | 0 | $0 |
| textsearch | 3 | 5,000 | 0 | $0 |

即：**本月已经产生了约 $8.7 的照片调用费**，且在新闸门上线前会继续按 $7/1000 涨到 $56 为止。

## 二、改动

### 1. 每个 SKU 用真实免费额度，且上限永远越不过额度（`src/lib/google-quota.ts`）

```ts
const FREE_TIER = { photo: 1000, details: 5000, textsearch: 5000, nearbysearch: 5000, ai: 400 };
```

- 上限 = `min(配置值 ?? 免费额度, 免费额度) × 0.9` —— **环境变量写得再大也会被压回免费额度以内**，
  所以配置错误也不可能产生费用。
- 逐 SKU 独立计数（Google 的额度是按 SKU 给的）。
- 旧的单一变量 `GOOGLE_API_MONTHLY_BUDGET` 仍兼容，但只能把上限**压更低**。
- 新增 `API_MONTHLY_BUDGET_<SKU>` 逐个覆盖。
- 计数放 D1，用带 `WHERE used < budget` 的 UPSERT 把「检查 + 加一」做成原子操作；
  **计数器出错时一律返回 false**（宁可不显示内容也不花钱）。

闸门实测值：photo 900 / details 4500 / textsearch 4500 / nearbysearch 4500 / ai 400。

### 2. AI（DeepSeek）也进闸门

DeepSeek 是余额制，之前 `/api/verify` 公开可刷 = 直接烧钱。现在每次**真正发请求**
（含重试）前先占一次 `ai` 额度，默认上限 400 次/月（`AI_MONTHLY_BUDGET` 可调）。

### 3. 鉴定改为必须登录

- `POST /api/verify`：服务端先查 session，未登录直接 `401 {"error":"unauthorized"}`。
- `/verify` 页面：未登录渲染「登录后才能鉴定」卡片 + Google 登录按钮（带 `callbackUrl`），
  不再渲染鉴定表单。
- `VerifyTool`：收到 401 时按站内既有做法（收藏按钮）跳 `/api/auth/signin?callbackUrl=...`。
